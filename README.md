# PE AirBrakes Readme File

Purpose
To give PE Airbrakes a functioning system of applications that will replace the original paper based recording of jobcards and record keeping with a modern digital system that allows customers to get quotes and book vehicles for repairs from the site or app and a desktop app that the admins can use to log job cards, keep records of jobs, trucks, parts, staff and invoices and returning customers

Changes Made

Mobile
- Technician overview which lets technicians see everything they need to(Assigned jobs, pending requests, breakdowns, jobs, updates and accepted jobs)
- Google SSO Sign in
- Language Changer
- Light and Dark mode
- GPS Tracking
- Writing to Database

  Website
  - Improvements in Validation for sending quotes and bookings
  - Dropdown menu for selecting the make and model of the truck
  - an other feature for adding models and makes that are not on the list
  - Descriptions while hovering over certain fields while creating a booking was added

    Desktop
    - Allowing the admin to see the tables in the database
